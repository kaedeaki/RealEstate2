# NLP Recommendation System for Investors to Find Right Builder  

**Aim**: This project aims to identify the best builders for Investors interested in real estate opportunities in Ontario, Canada.  
**Language**: Python, SQL, HTML, CSS  
**Tool**: Jupyter Notebook, PyCharm, Docker, Google Reviews, Flask, AWS RDS, MySQL, Git, GitHub, Spyder, Render  
**Solution**: Web Scraping, Extract reviews via API, Apply Flair and DistilBERT(LLM), Create DB    


1, Scrape data from the website by Spyder.
2, Clean and preprocess the data.
3, Use the Google Customer Reviews API to extract reviews for each builder.
4, Merge the extracted reviews.
5, Create a database and host it on AWS RDS.
6, Apply Flair and DistilBERT models for Named Entity Recognition (NER) and Sentiment Analysis using NLP techniques.
7, Deploy the model through a UI built with Flask, Docker, CI/CD pipelines, and GitHub.
